# موجة شات - MawjaChat

تطبيق أندرويد للتواصل الصوتي الخاص عبر تحويل الرسائل الصوتية إلى مخطط موجي دقيق يرصد الحروف، الكلمات، فترات السكون، والفراغات، ويرسلها للطرف المقابل عبر قناة خاصة محمية بـ (اسم المرسل + اسم المستقبل + الكود المشترك) ليقوم المستقبل بتحليل الموجة وإرجاعها إلى ملف صوتي قابل للتشغيل والحفظ بصيغة WAV.

## الميزات الجديدة (v1.1.0)
- **حذف الرسائل**: تلقائي بعد الاستماع (مفتاح في شاشة المحادثة) أو يدوي بزر سلة المهملات على كل رسالة.
- **مؤشر الاتصال**: نقطة خضراء = الطرف الآخر داخل التطبيق الآن، حمراء = غير متصل (مثل واتساب). يتطلب خادم `server/`.
- **إشعارات**: خدمة أمامية تُبقي القناة حيّة، وعند وصول رسالة والتطبيق في الخلفية يظهر إشعار (Android 13+ يطلب إذن الإشعارات).
- **حفظ الأسماء ومنع التكرار**: قائمة اقتراح لأسمائك وجهات الاتصال، منع تطابق المرسل/المستقبل، وحجز الاسم على مستوى الخادم لجهاز واحد.
- **واجهة جديدة** بنمط النيون الداكن حسب التصميم المرفق.

لتشغيل الخادم راجع `server/README.md`. الزر الرجوع داخل المحادثة يقطع الاتصال؛ أما الخروج للشاشة الرئيسية فيُبقيه شغالاً لاستقبال الإشعارات.
