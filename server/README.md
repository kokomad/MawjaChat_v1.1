# MawjaChat Relay

خادم WebSocket صغير يحتاجه التطبيق لتفعيل:
- مؤشر الاتصال (أخضر/أحمر) للطرف الآخر
- حجز الأسماء: كل اسم مستخدم مربوط بجهاز واحد فقط
- تمرير الرسائل الموجية بين طرفي القناة الخاصة

## التشغيل محلياً
```
cd server
npm install
npm start
```
ثم في التطبيق: الإعدادات ← رابط الخادم، مثال `ws://192.168.1.10:8080` (شبكة محلية) .

## النشر على الإنترنت
ارفع المجلد على أي استضافة Node (Render / Railway / Fly.io ...). ستحصل على عنوان `https://...`
فاستخدمه في التطبيق بصيغة `wss://...`. ملف `names.json` يحفظ الأسماء المحجوزة، فاجعله على قرص دائم إن أردت بقاءها بعد إعادة التشغيل (متغير `NAMES_FILE`).
